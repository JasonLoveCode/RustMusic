## 新功能

### Navidrome（Subsonic）在线音源
- 全新 Navidrome / Subsonic 音源接入：服务器连接（密码存 Windows 凭据管理器，不上传不落明文）、专辑库浏览、全曲库分页列表、搜索
- 播放 / 下载 / 加入队列 / 下一首播放 / 添加到播放列表，与本地及网易云 / QQ 音乐同等体验
- OpenSubsonic 同步歌词接入，旧版接口自动回退；播放页与桌面歌词同步展示
- 账号歌单浏览与导入
- **页面状态记忆**：切换到其它音源页再回来，原样恢复连接状态、当前页面、导航栈与滚动位置，不再闪登录页重新连接

### B 站登录用户收藏夹
- 在线音源页 B 站页签新增「我的收藏夹」：查看登录账号创建的全部自建收藏夹（含私密收藏夹）
- 收藏夹以标签展示，点击切换、超 30 条自动分页；视频行与 UP 主空间同款操作（播放 / 右键菜单 / 批量多选下载 / 字幕歌词）
- 结果区头部显示登录用户昵称与头像

## 修复

本版本对播放引擎、在线源与界面交互做了一轮系统性排查与集中修复（共 37 项）：

### 播放引擎 / 后端
- 修复酷狗设备注册在 dfid 未持久化时的无限递归（栈溢出 + 无限请求）：换新 mid 有界重试，仍失败明确报错
- 修复手动停止与播放监控的竞态：按停止键偶发自动切到下一首
- 修复 B 站 fragmented MP4 seek 约 1 秒误差与 seek 后进度漂移（时间戳亚秒精度 + 实际落点对齐）
- 修复酷狗榜单歌曲时长缩小 1000 倍（秒误当毫秒）
- 修复均衡器拖动滑块的咔哒声（换系数不再清零滤波器状态），拖动不再每像素一次 IPC
- 修复网络映射盘 / UNC 路径导入后静默扫描为 0 首
- 修复曾被软删除的曲目重新拖入后"导入成功却看不见"
- 修复 SMTC（系统媒体浮窗）首次播放在线曲目被封面下载阻塞最长 ~15 秒；封面路径含 `%` 时解析失败
- 修复手动停止时酷狗 / 网易云等的播放次数误计：播放失败不再计入"最近播放"
- 更新安装包下载增加 SHA-256 校验，校验不过拒绝静默安装

### 在线源 / 数据
- 修复网易云 / QQ / 酷狗搜索竞态：旧响应覆盖新结果、翻页追加错页（请求代次保护）
- 修复 UP 主空间切排序 / 进合集 / 翻页互相覆盖、已退出的合集被装回界面
- 修复 B 站扫码登录轮询在切换视图后永不停止
- 修复批量下载并发互抢进度条、同名文件互相写坏（改为串行队列），批量下载汇总失败数
- 修复批量收藏时旧快照覆盖新状态导致红心消失
- 修复酷狗用户歌单超过 250 首静默截断（改全量分页）
- 修复 b23.tv 短链不带协议头时无法解析
- 修复逐字歌词（yrc）任一行畸形导致整首降级行级：坏行只跳过该行
- 修复歌词加载失败后直到切歌都无法重试
- 修复手动排序保存的数据库事务问题（中断不再丢失整份排序）
- 修复按 track_id=0 删除会清光歌单内全部在线条目的隐患

### 界面 / 交互
- 修复桌面歌词从主窗口解锁后控制条 / 缩放手柄永不出现（窗口卡在无 UI 状态）
- 修复播放列表里 Navidrome 条目被当作 QQ 音乐渲染、收藏写错条目；顺带修复酷狗 / B 站行"正在播放"高亮永不出现

- 修复清空队列后出现巨大空白
- 修复快速连续拖拽排序会抓错行；侧边栏歌单拖拽无法滚到折叠区外
- 修复暂停状态下点歌词行高亮不跟随
- 修复右键菜单开着时后台刷新导致"播放"实际播第一首
- 修复持久化倍速值不在预设列表时点击直接跳 0.75x
- 修复"创建并添加"双击创建两个同名歌单
