# RustMusic v0.4.1

## 性能优化：渲染内存全面瘦身

本版本集中治理 WebView 渲染内存：此前长时间使用（大量滚动曲库 + 重度在线搜索）时 WebView2 内存峰值可达 1GB，托盘隐藏后回落也需要半分钟以上。现在有明显改善：

### 封面按需解码（最大项）
- 新增 160px 列表缩略图档：资料库 / 播放队列 / 歌单 / 底栏等小尺寸位置优先加载小图（解码内存 ~100KB/张，此前为 600px 全图的 ~1.4MB/张）
- 旧曲库升级后首次启动会在后台自动为存量封面补齐小图，无需重新扫描；补齐前自动回退原图，显示不受影响

### 自定义皮肤图片压缩
- 选图时自动生成 ≤1920px 的屏幕级压缩副本（动图 / 小图原样保留），4K/8K 壁纸不再整图解码常驻内存

### 扫描期内存峰值治理
- 曲库扫描的内嵌封面解码改为 4 线程专用池：不再按 CPU 核数并发整图解码，扫描期内存峰值从数百 MB 压到可控范围（扫描速度基本不变）

### 长时间使用不再只增不减
- 修复 B 站 API 响应缓存只存不清的问题：搜索 / 字幕等响应此前永久驻留且从不被读回，现只缓存必要接口并按容量淘汰
- 五个在线曲目元数据缓存（网易云 / QQ / 酷狗 / B 站 / Navidrome）加防御性容量上限，重度搜索 / 导入也不再无上限增长

### 托盘隐藏秒级落底
- 修复挂起后内存缓慢回落的问题：此前 TrySuspend 冻结 WebView 后 Windows 需 30 秒+ 惰性回收物理页，现在挂起完成后立即主动裁剪工作集，隐藏到托盘约 2 秒内内存从 ~800MB 落到 <100MB
- 桌面歌词窗口暂停时彻底停掉渲染循环，不再空转阻止内存回收

## 修复

- （无功能性修复；本版本不含行为变更，所有优化均带自动回退路径）
